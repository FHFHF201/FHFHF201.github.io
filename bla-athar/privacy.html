Privacy Policy – bla-athar

Last updated: 1 October 2026

1. Who we are and what this application does

"bla-athar" (the "API Client") is a private desktop tool operated by the owner of two YouTube channels: Film Recapped and No Trace (بلا أثر). It is used only by that channel owner to upload the channels' own narrated videos to YouTube and schedule when they are published. It is not offered to the public and has no other users.

2. YouTube API Services

This application uses YouTube API Services.

  • By using this application you agree to be bound by the YouTube Terms of Service.
  • Google's privacy practices apply to data processed through YouTube API Services: see the Google Privacy Policy (http://www.google.com/policies/privacy).
  • You can revoke this application's access to your data at any time on the Google security settings page.

3. Information we access, collect and use

With the channel owner's explicit consent through Google OAuth 2.0, the application requests the scopes youtube.upload and youtube, and uses them only to:

  • upload video files, titles, descriptions, tags and thumbnails that the owner produced, to the owner's own channels (videos.insert, thumbnails.set);
  • set the scheduled publish time and privacy status of those uploads, and correct their titles and descriptions (videos.update);
  • read the owner's own uploads list and their status to find the next free publishing slot (playlistItems.list, videos.list);
  • read the channel's name, ID and subscriber count to confirm which channel is linked (channels.list);
  • search public videos by a film's title to see how many recaps of that film already exist (search.list, videos.list), reading only public titles, channel names and view counts.

The application does not read, collect or store personal data about other YouTube users, viewers or commenters.

4. How information is stored and shared

  • The OAuth access and refresh tokens are stored only in a local file on the channel owner's own computer. They are sent only to Google's servers.
  • The only API data kept is the ID, URL and scheduled time of each uploaded video, and a count of existing public recaps for a suggested film, stored locally on the owner's computer.
  • No API data is sold, shared with third parties, combined with other data, or used for advertising.
  • This website and the application use no cookies, analytics or tracking technologies, and do not place or read cookies on users' devices.

5. Data retention and deletion

  • Locally stored API data is kept only while the channels remain linked, and is refreshed or deleted at least every 30 days as required by the YouTube API Services Developer Policies.
  • To delete all stored data, the owner revokes access on the Google security settings page and deletes the local token files; the application then holds no YouTube data.
  • If access is revoked, any remaining locally stored API data is deleted within 7 days.
  • Deletion requests can also be sent through the contact below and are completed within 7 days.

6. Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Changes and contact

Changes to this policy are posted on this page with a new "Last updated" date. Questions or deletion requests can be sent through the Film Recapped About page.
