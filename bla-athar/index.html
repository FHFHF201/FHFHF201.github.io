bla-athar

A private desktop tool that uploads and schedules narrated videos for two YouTube channels run by the same owner:

  • Film Recapped – full movie stories retold in minutes, in English.
  • No Trace (بلا أثر) – true crime stories, in Arabic.

It is not offered to the public. It uses YouTube API Services only to manage the owner's own uploads.
